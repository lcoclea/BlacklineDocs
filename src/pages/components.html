The screens are built from about fifty themed components in the NVSViewWidgets module. You can place them in your own Widget Blueprints. This page says what each one is for, which properties you set, and which events you can bind.

How components work

Every component except the button, tab strips and cut border derives from UNVSViewStyledWidget. Components never hold a colour, size or duration of their own. They name a role, such as ENVSViewColorRole::Accent or ENVSViewTypeRole::Heading, and resolve it from the style asset. Leave the Style property unset to use the style asset of the View Setup Definition in force. See Theming.

Most C++ classes are Abstract and have a shipped Widget Blueprint in /NVSBlackline/Widgets, named in the headings below, which carries the widget tree. Base classes have none. Subclass that asset, or place it as it is. Most components also expose many colour role properties, one per state. They are left out below because they only retint.

Events come in two kinds. Properties marked Blueprint below are BlueprintAssignable and appear in a Blueprint's event list. The rest are native delegates you bind from C++.

// A native event, bound from C++.
Tile->OnChosen().AddUObject(this, &UMyWidget::HandleTileChosen);

// A Blueprint event, also bindable from C++ as a dynamic delegate.
Tile->OnDoubleClicked.AddDynamic(this, &UMyWidget::HandleDoubleClicked);

Foundations

UNVSViewStyledWidget

The base for most components. It holds the optional Style asset and the resolvers, all Blueprint pure: ResolveColor, ResolveColorAtEmphasis, ResolveSpacing, ResolveMetric, ResolveTypeStep and ResolveDurationSeconds. Derive your own components from it to share the theme.

Text, W_Text

UNVSViewText is one line of text in a colour role and a type step. Headings, eyebrows and notes differ only in those two.

  • Text, ColorRole, TypeRole. What it says and how it looks.
  • bWrap. Wraps onto further lines. Off by default.
  • LineHeight. Overrides the step's line height. Zero keeps the step's own.
  • Justification. Horizontal alignment.

Blueprint callable: SetText, SetColorRole, SetTypeRole.

Button, W_Button

UNVSViewButton derives from UCommonButtonBase, so it keeps CommonUI's focus, hold and input action behaviour. It maps the reported state (normal, hovered, pressed, selected, disabled, focused) to token colours.

  • Label. The caption. A button bound to an input action shows the action's name instead.
  • Variant. A preset of roles, one of Secondary, Primary, GhostChip, Positive, Danger, Clipped, RailChip, MenuRow or Tab. Changing it rewrites the role properties, so set the variant before tuning roles by hand.
  • SubText, SelectedSubText. A second line under the caption.
  • CountText. A figure in the plate's corner, such as a filter count.
  • KeyCapText. A key drawn in a ruled square before the caption, such as ESC.
  • Icon, bShowIcon, bIconTrailing, bShowIconPlate. An icon and where it sits.
  • FillFraction, FillRole. A progress fill across the plate.
  • PlateRadius, PlateCut, PlatePadding, PlateSize. The plate's shape and size.
  • StyleTokens. The style asset. Named this way because the base class already has a Style property.

Blueprint callable: SetLabel. Click events are CommonUI's own, such as OnClicked().

Text input, W_TextInput

UNVSViewTextInput is a single-line field for search and chat. It wraps UEditableTextBox and applies every colour from the theme.

  • Hint. Shown while the field is empty.
  • Variant. Either Search (a plate with an icon, a count and a clear button) or InlineRename (a bottom rule only, at a larger size).
  • CountText. A figure at the right, such as 42 ITEMS.
  • bShowsClearMark, LeadingIcon, ClearIcon.

Blueprint callable: GetText, SetText, SetHint. Native events: OnCommitted() on Enter and OnEdited() on every change, both with the text.

Key hint, W_KeyHint

UNVSViewKeyHint is an input action icon with a caption. The icon, name and hold state come from the wrapped UCommonActionWidget.

  • Label, KeyText (the letter drawn while no action is bound), Form (Caption, Prompt or Quiet).

Blueprint callable: SetEnhancedInputAction, SetInputActionRow, SetInputActionBinding, SetLabel.

UNVSViewCutBorder

A UBorder with two opposite corners cut off, drawn as a polygon. CornerCut sets the cut in local units. Zero paints an ordinary border. It has no Widget Blueprint and appears in the palette like any border.

Navigation

Tab header, W_TabHeader

UNVSViewTabHeader is a themed UCommonTabListWidgetBase. CommonUI keeps the tab registry, selection and button pool. It adds active and inactive label and rule colours and passes its StyleTokens to each tab button. Blueprint pure: IsTabActive(FName TabNameID).

Sub nav, W_SubNav

UNVSViewSubNav is the contextual tab row at the top of a sectioned screen. It grows taller only when a tab carries a portrait plate, and draws nothing when the screen registers no tabs. FaceStandIn sets the text in an empty portrait. Screens fill it from their TabBindings.

Bottom chrome, W_BottomChrome

UNVSViewBottomChrome is the bottom bar with section tabs, contextual buttons and Deploy. Deploy follows the deploy queue's state wherever the bar is drawn.

  • DeployCaption. Deploy's resting caption.
  • LeaveCaption. Empty draws no leave button.
  • SectionWithOwnDeploy. The section whose screen has its own deploy button. Default Crew.
  • DeployCut, LockedOpacity.

A screen describes its contextual buttons with FNVSViewChromeAction (ButtonName, Caption, Variant, bQueueHero) in its ChromeActions array, and binds them by name.

Menu row, W_MenuRow

UNVSViewMenuRow is one item menu row with its word on the left and its key on the right. Label, KeyText, bActs (a row that cannot act is dimmed and takes no click) and InertOpacity.

Items and containers

See Items, Containers and Drag and drop for how screens use these.

Grid view, W_InventoryGrid

UNVSViewGridView draws a cell lattice and places one tile per entry. It never touches data. A drop fires an event and the screen raises the request.

  • GridSize. Size in cells. Zero takes no room.
  • Entries. An array of FNVSViewGridEntry, each with TopLeft, Footprint, EntryId, DisplayName, TagText, SecondaryValue and the item flags.
  • EntryWidgetClass. The tile class. A grid with none draws only the lattice.
  • TagArt, UntaggedArt. Icon and watermark per item tag, so a new category needs only a new row.
  • Accepts. A gameplay tag query for which items a drop may bring, set from the container's description. Empty takes anything.

Blueprint callable: SetEntries (sets entries and rebuilds the tiles in one call) and RebuildEntryWidgets. Blueprint pure placement helpers: GetCellPosition, GetEntrySize, GetDesiredGridSize, IsEntryInBounds. Native events: OnEntryDropped (grid, drag, top-left cell), OnEntryDroppedOnItem, which returns whether the drop was taken, and OnEntryRefused when Accepts turns a drop away.

Item tile, W_ItemTile

UNVSViewItemTile is one rendered item. It knows its footprint but not its position, so it also works in lists.

  • ItemId, DisplayName, TagText, SecondaryValue, Footprint.
  • bShowTag, bShowSecondaryValue.
  • ItemTags, FitsSlot, InsideId, AttachKind, bUsable, Price, Count, RenderArt. Carried to drags, the item menu and the inspect window. FitsSlot is a slot tag under NVS.View.Slot and AttachKind an attachment kind tag.
  • bQuestLit, bUnaffordable, bLitBySearch, bFadedBySearch. States set by the host.
  • Icon, Watermark. Set by the grid from its tag table.

Blueprint events: OnPressed, OnClicked, OnContextMenuRequested, OnDoubleClicked, OnHoverBegin, OnHoverEnd. Native event: OnChosen() with the tile.

Equip slot, W_EquipSlot

UNVSViewItemSlot is a labelled single-item socket, in an inline row form or a square tile form.

  • SlotId, Accepts. Which socket, and a gameplay tag query for extra items it takes on top of items made to be worn there.
  • Label, ItemName, bFilled, bStripped.
  • bFixed, bKeptOn. A worn item that cannot be taken, like trousers on a body, shown faded. Or one that stays on, like your own secure case, which looks normal but cannot be dragged or taken off.
  • bTile, InlineForm, TileForm. The two layouts.
  • MountCount, FittedCount, MountsFormat. The mounts line.
  • bAttachment, AcceptsKinds, bDragsOut, FittedItemId, SlotAddress. For a slot on an item instead of on the figure. With AcceptsKinds set, it takes any attachment and the drop finds the matching slot.
  • EmptyText, DropValidText, DropInvalidText, StrippedText.

Blueprint events: OnPressed, OnContextMenuRequested, OnDoubleClicked, OnHoverBegin. Native event: OnItemDropped with the slot and the drag.

Belt cell, W_BeltCell

UNVSViewBeltCell is a quick belt cell, a socket like the doll's with its key at the top left. Adds KeyText (1 to 8) and EmptyBeltText.

Paper doll, W_PaperDoll

UNVSViewPaperDoll is three tracks by five rows of fixed cells, with the character render in the clear middle track. Its tiles are equip slots in tile form, built at runtime.

  • Tiles. One FNVSViewDollTile per socket, with SlotId, Column, Row, Span and PairedWith.
  • Columns. The number of column tracks. The middle one stays clear for the figure.
  • SocketArt, TileClass, TilePrefix, FigureNoteText.
  • TilePlateOpacity, EmptyTilePlateOpacity. So the figure shows through.
  • PreviewProfile. How the figure behaves here. The shipped doll uses PP_Doll, a still figure. See Rendering.
  • bFitsHeight, bSpreadsRows.

Container block, W_ContainerBlock

UNVSViewContainerBlock is the labelled square beside a worn container's grids. Its capacity line is summed from Pouches, one FNVSViewContainerPouch (PouchId, GridSize, OccupiedCells) per grid. Also Label, ContainerName, CapacityFormat, Icon and Watermark. Blueprint events: OnPressed, OnContextMenuRequested, OnDoubleClicked, OnHoverBegin.

Search veil, W_SearchVeil, and search badge, W_SearchBadge

UNVSViewSearchVeil is an opaque hatched cover over an unsearched grid. It has no clock, so the caller drives Progress from 0 to 1 and can scrub or cancel. Also GridSize, bSearching, bSearched, bCompact and DurationSeconds. UNVSViewSearchBadge draws a container's search State as a coloured word.

Drop slot, W_DropSlot

UNVSViewDropSlot is a crafting or upgrade part slot filled by dragging from the stash. State is Empty, Loaded or InTheJob, with ItemName, WantsText and the state words. Native event: OnItemDropped with the drag. Derives from the plate tile below.

FNVSViewItemSubject

Not a widget. The struct the item menu and inspect window receive, describing the item as its tile or slot showed it. Place is a tag under NVS.View.Place: Stash, Pack, Rig, Pockets, Secure, Loot, Trader, Worn, Crew, Attached or Wardrobe. The item menu matches each Item Action Definition's queries against the item's tags plus its place and state, which Get Item Tag Set in the screen library returns. See Context menu.

Record rows and cards

These are list entries. Each borrows a record viewmodel from a list and rewrites every field on arrival, so a recycled widget shows nothing of its last row. Screens fill them from RailBindings.

UNVSViewListEntry

The base, implementing IUserObjectListEntry. PrimaryText, SecondaryText and bShowSecondaryText. Blueprint pure: GetBoundViewModel.

Record row, W_LoadoutRow

UNVSViewRecordRow is a four-field row with a rule on its left edge. Adds StatusText, DetailText, bLocked, LockedCountText, RowInset, bDrawsHairline, bShowIconPlate and Icon. Native event: OnChosen() after a click selects the row. Screens use it for loadouts, jobs, recipes and power loads.

Record card, W_RecordCard, and perk card, W_PerkCard

UNVSViewRecordCard is a record as a card with a status, a paragraph and a foot line, tinted by state. Adds StatusText, BodyText, DetailText and CardPadding. UNVSViewPerkCard adds the link from the tier above (bShowLink, bLinkTaken), a ring when chosen (bChosen) and a native OnChosen() event.

Figure row, W_FigureRow, and meter row, W_MeterRow

UNVSViewFigureRow is a caption on the left and a figure on the right. Adds bDrawsDot, DotSize, RowPadding, bDrawsRule and bFigurePlated. UNVSViewMeterRow adds a bar from the meter with the row's own id (bShowMeter, MeterValue, MeterMax) and two more lines, DetailText and NoteText.

HUD row, W_ExfilRow and W_CrewRow

UNVSViewHudRow is a record drawn bare over gameplay. bDrawsAccentEdge and bDrawsBox.

Objective row, W_ObjectiveRow

UNVSViewObjectiveRow is a task step with a box and its state. bBoxFilled and bStruck mark a done step.

Chat line, W_ChatLine

UNVSViewChatLine is a time column, then the speaker and the message. An empty SpeakerText marks a system line. TimeWidth sets the time column.

Standing, W_Standing

UNVSViewStanding stacks caption, figure and NoteText, with no plate unless bDrawsPlate is set.

Crew card, W_CrewCard

UNVSViewCrewCard is a lobby seat with the name over a state line, and a lock-in effect when a match is found. RecordId, PingText, MetaText, KitLines (the first three FNVSViewCrewKitLine are drawn), bOwnSeat, SeatIndex, bLockingIn and the sweep, charge and glow timings. Native event: OnChosen().

Meters and readouts

Stat meter, W_StatMeter, W_LimbBar and W_LoadBar

UNVSViewStatMeter is a label, a value, a bar and threshold colouring. The band reads the unclamped ratio and the bar fills from the clamped one, so an over-capacity meter turns red while its bar is full. Three assets share this class.

  • Label, ValueText. The caption and the figure as you format it.
  • Value, MaxValue, WarnFraction, CriticalFraction, bLowIsAdverse.
  • bStated. One fixed colour, full, instead of banding.
  • Icon, IconSize, BarThicknessOverride.

Blueprint callable: SetValue, SetRange, SetLabel, SetValueText. Blueprint pure: GetValueFraction, GetFillFraction, GetBand.

Encumbrance, W_Encumbrance

UNVSViewEncumbrance is the load card with the tier, kilograms, a track of tier steps and what dropping weight would gain. Set CarriedKg, and optionally Tiers (ascending FNVSViewLoadTier, each a Label and LimitKg). With Tiers empty it uses the Load Tiers of the View Setup Definition. Every word comes from the formats it exposes, such as TierAndLoadFormat and DropToFormat.

Signature, W_Signature

UNVSViewSignature shows how loudly the character moves and how well it hears, from three worn sockets and the load. Inputs bWearsBoots, BootsWeightKg, bWearsHeadset, bWearsFaceCover and CarriedKg, thresholds HeavyBootsKg and NoisyLoadKg, and the socket ids it reads, BootsSlotId, EarsSlotId and FaceSlotId.

Body zone, W_BodyZone

UNVSViewBodyZone is one body zone with its name, hit points, a bar and a chip per state. Label, HitPointsText, Fraction, StatesText (each term becomes a chip), NoteText, bChosen, bBlackedOut and bCard for the larger form. Native event: OnChosen().

Generator, W_Generator

UNVSViewGenerator draws a generator's fuel slots and readout. CanLevels (one fraction per slot, zero or less is empty), DrawKilowatts, CapacityKilowatts, HoursPerCan, LowCanFraction, LowFuelFraction and CansInStash. Native events: OnCanDropped with the slot index and the drag, and OnEmptySlotPressed. On the generator screen, a can dropped on an empty slot raises Station.Feed, the same request as Add fuel, and the player's Inventory component moves the can from the stash into the tank. See The generator.

Cards and tiles

UNVSViewPlateTile

The base for flat cards with a square plate, a state badge, an eyebrow, a name and a foot line. EyebrowText, Art, GlyphArt, TileWidth and layout padding. Subclasses say what each state paints.

Catalogue tile, W_CatalogueTile

UNVSViewCatalogueTile is a wardrobe or shop tile. State is Locked, Owned, Worn or Selected, with ItemName, PriceText and the state words. Native events: OnChosen() and OnInspect() on a double-click.

Station card, W_StationCard

UNVSViewStationCard is a hideout station. State is Ready, Working, Idle or NotBuilt, with NameText, LevelText, LineText, DrawText, ActionText, Progress and Art. Native event: OnChosen().

Trader card, W_TraderCard

UNVSViewTraderCard is a trader with a portrait plate, name, loyalty, description and standing bar. NameText, TradeText, PlaceText, LoyaltyText, BlurbText, RateText, StandingFraction, bChosen and CardSize. Native event: OnChosen().

Upgrade row, W_UpgradeRow

UNVSViewUpgradeRow is one level of an upgrade path. State is Installed, Next or Later, with CostText, LevelText and GainText. Levels past the next are hatched.

Market

These three are filled by the market screen from C++ and expose few editable properties. See Market and trading.

Listing row, W_ListingRow

UNVSViewListingRow is one market row, or one of the player's own listings. Fill it with SetListing or SetOwnListing. PinArt sets the pin icon. Native events: OnChosen, OnPinned and OnAction, each with the listing id.

Catalogue row, W_CatalogueRow

UNVSViewCatalogueRow is one item type with how many are listed and the lowest price. Native event: OnChosen with the type id.

Bid row, W_BidRow

UNVSViewBidRow is one bid in a listing's history. Yours draw in the accent.

Settings rows

The rows show values the host writes. They hold no registry and save nothing. See Settings.

UNVSViewSettingRow

The base, a list entry with a label, an optional description and one value readout.

Bool row, W_SettingRowBool

UNVSViewSettingRowBool is an on and off toggle. bValue, OnText, OffText and the track and knob sizes. Blueprint callable: SetValue, ToggleValue, GetValue.

Choice row, W_SettingRowEnum

UNVSViewSettingRowEnum is a one-of-several row with options as text. Options, SelectedIndex, Presentation (Auto uses chips for up to four choices and a stepper beyond) and DropdownClass with DropdownRowClass. Blueprint callable: SetSelectedIndex, SetOptions, SelectNext, SelectPrevious.

Slider row, W_SettingRowSlider

UNVSViewSettingRowSlider is a ranged row that clamps and snaps what it is given. MinValue, MaxValue, StepSize (zero is continuous), Value, ValueSuffix and DisplayFractionalDigits. Blueprint callable: SetValue, SetRange.

Key-bind row, W_SettingRowKeybind

UNVSViewSettingRowKeybind captures a key when its chip is clicked, with held modifiers joining it. A clash offers Swap or Clear. UnboundText, ListeningText and ConflictFormat. The player's key profile stores the binding.

UNVSViewSettingDropdown

The choice list a choice row opens under its value chip, as a Slate menu so the settings list cannot clip it. It has no Widget Blueprint. Native events: OnChosen with the index, and OnClosed.

Input test strip, W_InputTestStrip

UNVSViewInputTestStrip lights each bindable action as Enhanced Input fires it, so a rebinding can be checked with no character in the level. The settings screen shows it on the Controls category. From C++, Start(ULocalPlayer* Player) and Stop().

Notifications

Toast, W_Toast

UNVSViewToast is one rendered notification. Repeats, timing and holding back belong to UNVSNotifySubsystem. Payload, bBare for the HUD form, bDrawsEdge, bTitleIsStatus, ActionText and DismissText. Blueprint callable: SetPayload. The colours come from the Notification Kind Definition whose tag matches the payload's most closely, then from the plugin's built-in kinds. A payload with an ActionTag draws an action button and a dismiss button. The action raises the Notify.Act request and dismisses the toast. See Notifications.
