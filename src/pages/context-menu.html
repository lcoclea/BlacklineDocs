Right-clicking an item opens a menu of what the player can do with it where it sits. Each row is an Item Action Definition data asset, so you add a row, change a shortcut or hide a row by making an asset. No code is needed.

How it opens

  • Right-click a tile in a grid, a filled doll slot or a worn container block.
  • The menu opens at the pointer above every window, and it stays inside the screen edges.
  • Any click outside closes it. Choosing a row closes it and does the action.

Rows can also be chosen without the menu, by their gesture: Ctrl-click, Alt-click, Shift-click, double-click or a key over the item. That is how every shortcut on the Drag and drop page works.

The rows that ship

The plugin ships seventeen rows in Content/Settings/ItemActions, listed here in their sort order. A row shows only when the item matches its Offered When.

Open (double-click)
A bag or crate lying in a grid, or a worn container with a pop-out. Opens its grids in a window. Not on a trader's shelf or a teammate's gear.
Use
A consumable lying in a grid. Not on a trader's shelf or a teammate's gear.
Detach
An attachment fitted to a weapon. Moves it to the first place with room.
Inspect (double-click)
Every item. Opens the inspect window. An item that opens a container keeps double-click for Open, because the first row to claim a gesture keeps it.
Equip · SLOT (Alt-click)
An item in a grid that names a slot. Greyed out when the slot is taken.
Move to WINDOW (Ctrl-click)
An item in a grid while a container window is open in front. Moves it into that window.
Move to your gear (Ctrl-click)
An item in the stash. Moves it to the rig's pouches, the pockets or the pack, the first with room. Shown only when no earlier row took Ctrl-click.
Move to stash (Ctrl-click)
An item in the pack, rig or pockets. Shown only on a screen with a stash, and only when no earlier row took Ctrl-click.
Unequip (E)
A worn item that is not fixed. Greyed out when the stash has no room.
Take into GEAR (Ctrl-click)
Loot from a crate or body. Moves it into your gear.
Move to rig, Move to pack
Between the worn pack and rig.
Buy · PRICE
An item on a trader's shelf.
Sell · OFFER
An item in the stash.
Rotate (R)
The player's own loose items. Greyed out unless the item lies in a grid.
Split stack (Shift-click)
The player's own loose items. Greyed out unless there is more than one in the stack.
Drop (Delete)
The player's own items that are not worn, fixed or fitted.
Edits to the plugin's own assets are replaced when you update the plugin. To change a shipped row, make your own asset that replaces it, as shown below.

What a row holds

Open any of the shipped rows to see these fields in the Details panel.

Action
The request the row raises, as a gameplay tag, such as NVS.View.Request.Item.Drop. Two tags are handled by the screen itself: NVS.View.Action.Inspect opens the inspect window and NVS.View.Action.Open opens a container. Any other tag, including one of your own, is raised as a request.
Label
The row's text. It may name {Target}, {Slot}, {Price} (the shelf price) and {Offer} (what a sale fetches).
Short Label
Shown instead when a name in the label has nothing to fill it, such as Move to your gear when there is no target name.
Key Hint
The text at the right of the row, such as CTRL CLICK.
Gesture, Key
The shortcut that picks the row: None, Double Click, Ctrl Click, Shift Click, Alt Click, or Key with a Key such as R.
Only When Gesture Free
Hides the row when an earlier row already took its gesture. Otherwise the row stays and loses its shortcut and hint.
Role
The row's colour from the theme, such as Danger for Drop or Success for Sell.
Offered When
A gameplay tag query. Empty offers the row for every item.
Enabled When
A second query. When it does not match, the row shows greyed out.
Target, Target Place
What the row acts on, which also decides when it has room. See below.
Hidden Without Place
Hides the row on a screen that has no grid in Target Place.
Replaces
A row this one stands in for. Leave Action empty to hide that row.
Sort Order
Lower comes first. The shipped rows use 10 to 170 in steps of 10.

What the queries match

Offered When and Enabled When are matched against the item's own Tags plus two kinds of tag the screen adds:

NVS.View.Place
Where the item is: Stash, Pack, Rig, Pockets, Secure, Loot, Trader, Worn, Crew (a teammate's gear, view only), Attached or Wardrobe.
NVS.View.ItemState
What it is like now: InGrid, Stack, Usable, Opens, Fixed, Equippable or Attachable.

Get Item Tag Set on NVS View Screen Library returns this combined set for an item, which helps when testing a query.

Targets

None
The item itself.
Fits Slot
The doll slot the item fits. Acts when that slot can take it.
Worn Slot
The slot the item is worn in. Acts when Target Place, if set, has room.
Open
What the item opens. Not offered when it opens nothing.
Front Window
The container window in front. Not offered without one, or when it shows the item's own container.
Gear
The first of the rig, the pockets and the pack with room. Not offered on a screen without a pack.
Place
Target Place. Acts when it has room.
Detach
The first place with room for a fitted attachment.

Add your own row

This example adds a Repair row for weapons in the stash.

  1. Make a tag In Project Settings > Gameplay Tags, add Game.Item.Repair.
  2. Create the asset Make a Data Asset of class Item Action Definition, such as DA_ItemAction_Repair, anywhere in your Content folder. The plugin finds it by itself.
  3. Fill it Set Action to Game.Item.Repair, Label to Repair and Sort Order to 145, so it sits between Sell and Rotate. Set Offered When to a query that needs all of Item.Weapon and NVS.View.Place.Stash.
  4. Give it a key if you like Set Gesture to Key, Key to a free key and Key Hint to its name.
  5. Answer it In your player controller, get the NVS View Request Subsystem with Get Local Player Subsystem, bind On Request, and check whether the request's Request Id matches Game.Item.Repair.

The request carries the item. Item Id is the item's definition and its instance joined by @, such as NVSViewItem:PDA_AR4@I3. The part after @ is the instance id the Inventory component's calls take. Item Name and Item Tags are filled too.

Change or hide a shipped row

  1. Create your row Make a new Item Action Definition and set Replaces to the shipped row, such as DA_ItemAction_Drop.
  2. Change it Copy the fields you want to keep and change the rest, such as the Key. Your row now shows instead of the shipped one.
  3. Or hide it Leave Action empty. The shipped row disappears and yours shows nothing.

Result

With the Repair row in place, press Play, open the stash and right-click a rifle. Repair appears between Sell and Rotate. Choosing it raises Game.Item.Repair, and your On Request handler receives the rifle's id. Right-click a bandage and Repair does not appear.
