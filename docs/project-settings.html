Project settings

Blackline keeps its project-wide choices in two data assets instead of a Project Settings page. One sets the theme, the screens, icon rendering, money and load. The other names the sound classes and input assets the settings screen drives. This page lists every field.

The two setup assets#

Data assetClassModuleThe plugin's own
View Setup DefinitionUNVSViewSetupDefinitionNVSView/NVSBlackline/Settings/Setup/DA_BlacklineSetup
Engine Settings Setup DefinitionUNVSViewEngineSetupDefinitionNVSViewSettings/NVSBlackline/Settings/Setup/DA_BlacklineEngineSetup

The plugin's own assets use the defaults below. To make your own choices, create your own setup asset in your project. The plugin looks for it by itself, and a setup in your project always wins over the one the plugin ships. If you make several View Setup Definitions, the one with the highest Sort Order wins.

  1. Create it In your Content folder, right-click and choose Miscellaneous > Data Asset, then pick View Setup Definition. Name it, for example PDA_MySetup.
  2. Change what you need A new asset starts with the same defaults as the plugin's, which point at the plugin's own style, layout and screen registry. Change only the fields you care about.
  3. Press Play The screens use your setup from then on. There is nothing to register.

Do the same with an Engine Settings Setup Definition when you want to change the audio or input assets.

One engine setting does belong in Project Settings. CommonUI routes its input through its own viewport client, so set Project Settings > Engine > General Settings > Game Viewport Client Class to CommonGameViewportClient. The demo project is set up this way.

View Setup Definition#

Game#

FieldDefaultWhat it does
GameTitleEmptyThe wordmark on the hub. Empty uses the project's name.
KeyArtEmptyThe picture beside the hub. Empty shows no picture.
RegionImageEmptyThe picture of the whole region on the location screen, under one point per raid map. Empty draws a plain grid.

Style and layers#

FieldDefaultWhat it does
StyleAsset/NVSBlackline/DA_BlacklineStyleThe theme every component uses unless its own Style property overrides it. If it cannot load, components fall back to built-in colours with no font, and LogNVSView warns. See Theming.
LayoutAsset/NVSBlackline/DA_BlacklineLayoutThe layer table the layer stack is built from.
ScreenRegistry/NVSBlackline/DA_BlacklineScreenRegistryThe screens Show Screen By Tag can open, and the widget each screen tag opens. Point a row at your own Widget Blueprint to replace a screen everywhere.

Render#

FieldDefaultWhat it does
IconsPerFrame2 (1 to 16)The most item icons rendered in one frame. The rest wait in a queue.
IconCacheMegabytes64 (at least 8)Above this size, icons nobody is showing are dropped, oldest first.
IconMaxPixels512 (64 to 4096)The largest an item icon is drawn, along its long side. Raise it for sharp icons in big tiles at 4K.
IconMargin1.08 (0.5 to 3)How much room is left around an item in its icon. 1 fits it edge to edge.
IconCutoutMaterial/NVSBlackline/Render/M_IconCutoutThe UI material that cuts a capture out of its background. It takes the capture as its Render parameter.
KeyLightIntensity, FillLightIntensity, RimLightIntensity, SkyLightIntensity6, 2, 4, 1The brightness of the lights item icons and figure previews are captured under.
KeyLightDirection, FillLightDirection, RimLightDirection(-40, -35, 0), (-15, 145, 0), (-25, 180, 0)Where the main light, the softer fill light and the edge light come from, as pitch, yaw and roll.

See Rendering.

Money#

FieldDefaultWhat it does
CurrencySymbol€Written before every amount.
bSymbolAfterAmountfalsePuts the symbol after the amount with a space, as in 5,200 kr.
ThousandsSeparator,Goes between each group of three digits.

Load#

FieldDefaultWhat it does
LoadTiersSPRINT to 12 kg, JOG to 18 kg, WALK to 24 kgThe load track's tiers, fastest first, each with its word and the weight it ends at. Get Load Tier returns the tier the player's carried weight falls in, from 0 for the lightest, or -1 when over the last one. Your movement code decides what each tier allows. An empty list draws no track.
HeavyBootsKg1.2Boots at or above this weight count as loud on the noise signature. 0 never does.
NoisyLoadKg18A load above this adds a step to the noise signature. 0 never does.

The demo project sets its tiers to SPRINT 20, JOG 28 and WALK 36 kg.

Words and slots#

FieldDefaultWhat it does
TagNamesEmptyThe word shown for a tag, such as a slot (NVS.View.Slot.Primary), a kind of item or a calibre. A tag not listed shows the last part of its name in capitals.
AllFilterIconallThe icon on the filter tab that shows every item.
SlotBodyZonesHead, ears, eyes and face to head. Armour, rig and pack to chest. Gloves and watch to arms. Legs, boots and sidearm to legs.The part of the body the character preview turns to when the player points at a slot's gear. A slot not listed gets no turn.

Loot#

FieldDefaultWhat it does
SearchBaseSeconds0.8Seconds every search takes before the container's size counts.
SearchSecondsPerCell0.12Seconds each cell of a container adds to its search.
SearchBodyFactor0.6Searching a body's gear takes this share of the time a crate of the same size would.

Engine Settings Setup Definition#

These name the assets the settings screen's engine-backed rows drive. The audio defaults point at assets in /NVSBlackline/Settings/Audio/. Replace them with your own, or parent your game's sound classes under the shipped ones. See Settings.

FieldDefaultWhat it does
SoundMixSCM_NVSSettingsThe sound mix the volume rows adjust.
MasterClass, MusicClass, EffectsClass, VoiceClass, InterfaceClassSC_NVSMaster, SC_NVSMusic, SC_NVSEffects, SC_NVSVoice, SC_NVSInterfaceThe sound class each volume row drives.
NightModeEffectSFX_NVSNightModeAdded to the master submix while dynamic range is set to Night.
bDriveFieldOfViewtrueScales each player's camera field of view by their saved value. Turn it off if your game sets the field of view itself.
AuthoredFieldOfView90 (5 to 170)The field of view your cameras are built with. A player who picks this value sees your cameras unchanged.
RevertWindowSeconds15How long a display change, such as a new resolution, waits for the player to keep it before it goes back.
MaxVisibleNotifications4The most toasts on screen at once.
MaxHeldNotifications4The most toasts held back while a menu is open, shown once it closes.
BackKeysEscape and the gamepad's right face buttonThe keys that close the topmost screen.
ActionSetEmptyThe input actions the Controls tab lists for rebinding. Set it to an action set of your game's actions.
ContextPriority100The priority of the input mapping context that holds the player's rebound keys. Keep it above your game's own contexts so a rebound key wins.

Per-player values#

UNVSViewSavedSettings holds the setting values the engine does not store itself, per player, in GameUserSettings.ini. Your game reads them through its getters from C++.

#include "Settings/NVSViewSavedSettings.h"

const UNVSViewSavedSettings& Saved = UNVSViewSavedSettings::Get();
const float Sensitivity = Saved.GetMouseSensitivity();
const bool bInvert = Saved.IsInvertY();
GetterSetting id
GetFieldOfView()Video.FieldOfView
GetMouseSensitivity()Controls.MouseSensitivity
GetAimSensitivity()Controls.AimSensitivity
IsInvertY()Controls.InvertY
IsAutoReload()Gameplay.AutoReload
GetHoldToLootSeconds()Gameplay.HoldToLoot
ShowsCorpseMarkers()Gameplay.CorpseMarkers
WarnsCarryWeight()Gameplay.CarryWeightWarnings
GetDynamicRange()Audio.DynamicRange (0 wide, 1 night)
GetSubtitleSize()Accessibility.SubtitleSize (0 small, 1 medium, 2 large)
IsHighContrastHud()Accessibility.HighContrastHud
ReducesScreenShake()Accessibility.ReduceScreenShake

The class also keeps the player's key bindings, and its OnValueChanged fires with the setting id when a value changes.
