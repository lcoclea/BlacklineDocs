# Blackline docs

Guides for **Blackline**, the extraction-shooter interface plugin for Unreal Engine 5.8.

Read them at https://lcoclea.github.io/BlacklineDocs/

Questions and bug reports go in [Issues](https://github.com/lcoclea/BlacklineDocs/issues).

The site is built from `src/` with `python build.py`, which writes `docs/`.
